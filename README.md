# 과초점 · 심도 계산기

수동 렌즈로 팬 포커스와 존 포커싱을 할 때 쓰는 계산기입니다.

**바로 쓰기:** https://DreamerKMP.github.io/dof-calculator/

파일 하나(`index.html`)로 되어 있고 외부 글꼴이나 라이브러리를 쓰지 않아서, 받아두면 인터넷 없이도 그대로 동작합니다.

## 기능

- **과초점 거리**와 그때의 선명한 범위 계산
- 초점 위치를 바꿨을 때 **가까운 끝 ~ 먼 끝** 계산, 거리 축 위에 시각화
- 센서 프리셋: APS-C 후지(23.5 × 15.6mm), 풀프레임, 마이크로포서드
- 착란원(c) 선택: 일반 / 엄격 / 픽셀 기준 / 직접 입력
- 현재 렌즈의 **조리개별 과초점표** (줄을 누르면 바로 적용)
- **존 포커싱 역산**: 선명하게 담고 싶은 구간을 넣으면 초점 위치와 필요한 조리개를 계산
- 마지막 설정을 기기에 저장

## 오프라인에서 쓰기

1. 저장소에서 `index.html`을 내려받습니다.
2. 폰의 내 파일 앱에서 파일을 눌러 브라우저(삼성 인터넷, 크롬)로 엽니다.

위 주소로 여는 온라인 버전은 인터넷이 있어야 열립니다. 설정 저장도 온라인 버전과 내려받은 파일이 따로 기억합니다.

## 계산식

| 항목 | 식 |
|---|---|
| 과초점 거리 | `H = f² ÷ (N × c) + f` |
| 가까운 끝 | `s(H − f) ÷ (H + s − 2f)` |
| 먼 끝 | `s(H − f) ÷ (H − s)`, s ≥ H이면 무한대 |

`f` 초점거리, `N` 조리개 값, `c` 착란원, `s` 초점을 맞춘 거리. 단위는 모두 mm.

착란원 기준:

- 일반: 센서 대각선 ÷ 1500 (APS-C 약 0.019mm)
- 엄격: 센서 대각선 ÷ 2800 (APS-C 약 0.010mm)
- 픽셀: 픽셀 두 개 크기

## 주의할 점

- 공식은 일반 렌즈를 전제로 합니다. 어안 렌즈에서는 근사값입니다.
- 저렴한 수동 렌즈는 거리 눈금이 실제와 다를 수 있습니다. 처음 한 번은 가까운 물체와 먼 배경을 찍어 확대해서 확인하고, 맞는 위치를 초점링에 표시해두세요.
